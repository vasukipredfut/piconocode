## 💡 Common Scenarios & Workflows

### Scenario 1: New Employee Joins Company

**Steps**:
1. HR creates employee record (see [HR Module - Section 2](03-HR_MODULE.md#2-employee-management))
2. System admin assigns roles and permissions (see [Getting Started - Section 7](01-GETTING_STARTED.md#7-user-roles--permissions))
3. Employee logs in and changes password (see [Getting Started - Section 2](01-GETTING_STARTED.md#2-first-time-login-steps))
4. Employee completes profile (see [System Navigation - Section 9](02-SYSTEM_NAVIGATION.md#9-user-profile--settings))

**Estimated Time**: 30 minutes

---

### Scenario 2: Processing Monthly Payroll

**Steps**:
1. HR verifies all attendance is marked (see [HR Module - Section 3](03-HR_MODULE.md#3-attendance-management))
2. HR processes payroll (see [HR Module - Section 5](03-HR_MODULE.md#5-payroll-management))
3. Manager/Admin reviews payroll (see [HR Module - Section 5](03-HR_MODULE.md#5-payroll-management))
4. HR approves payroll (see [HR Module - Section 5](03-HR_MODULE.md#5-payroll-management))
5. Generate and distribute salary slips (see [HR Module - Section 5](03-HR_MODULE.md#5-payroll-management))

**Estimated Time**: 2-3 hours

---

### Scenario 3: Creating Purchase Order

**Steps**:
1. Employee creates purchase requisition (see [Procurement Module - Section 3](05-PROCUREMENT_MODULE.md#3-purchase-requisitions-pr))
2. Manager approves PR (see [Procurement Module - Section 3](05-PROCUREMENT_MODULE.md#3-purchase-requisitions-pr))
3. Procurement converts PR to PO (see [Procurement Module - Section 3](05-PROCUREMENT_MODULE.md#3-purchase-requisitions-pr))
4. Procurement sends PO to vendor (see [Procurement Module - Section 4](05-PROCUREMENT_MODULE.md#4-purchase-orders-po))
5. Receive goods when they arrive (see [Procurement Module - Section 5](05-PROCUREMENT_MODULE.md#5-goods-receipt--inspection))
6. Process vendor invoice (see [Procurement Module - Section 6](05-PROCUREMENT_MODULE.md#6-vendor-invoice--payment))

**Estimated Time**: 1-2 days

---

### Scenario 4: Inventory Stock Take

**Steps**:
1. Identify low stock items (see [Inventory Module - Section 3](04-INVENTORY_MODULE.md#3-stock-management))
2. Conduct physical count (see [Inventory Module - Section 3](04-INVENTORY_MODULE.md#3-stock-management))
3. Record adjustments (see [Inventory Module - Section 3](04-INVENTORY_MODULE.md#3-stock-management))
4. Generate stock valuation report (see [Inventory Module - Section 6](04-INVENTORY_MODULE.md#6-stock-valuation))

**Estimated Time**: 4-8 hours (depending on inventory size)
